Global Infectious Disease Data Acquisition

Introduction

This project collects infectious disease data from the World Health Organization (GHO) Global Health Observatory API. Our goal is to create a clean dataset containing cases, deaths, incidence rates, and mortality rates across countries and years. The data will also be used in our final interactive infectious disease dashboard.

Our initial focus is malaria, followed by tuberculosis and HIV.

Creating Function to Retrieve Data from WHO

We create a custom function to retrieve data from the WHO API. The function takes an indicator code and returns a tibble containing country, year, and the corresponding statistic.

# Function to retrieve an indicator from the WHO API
get_who_data <- function(indicator_code, variable_name) {

  url <- str_c(
    "https://ghoapi.azureedge.net/api/",
    indicator_code
  )

  
#request API using specified indicator code  
  
  response <- request(url) |>
    req_perform()


#extract data from API response
  
  data <- response |>
    resp_body_json(simplifyVector = TRUE)

  records <- data$value


#filter data to only include countries and single observations instead of different data by sex

  as_tibble(records) |>
  filter(SpatialDimType == "COUNTRY") |>
    filter(
        is.na(Dim1Type) |
        Dim1Type != "SEX" |
        Dim1 == "SEX_BTSX"
    ) |>
  
#select + rename columns
       
  select(
    country_code = SpatialDim,
    year = TimeDim,
    value = NumericValue,
    low = Low,
    high = High
  ) |>

#make the time an integer instead of character and name columns by specified variable input + add low and high columns for interval values
    
  mutate(year = as.integer(year)) |>
  rename_with(
    ~ c(variable_name,
        paste0(variable_name, "_low"),
        paste0(variable_name, "_high")),
    c(value, low, high)
  )
}

Malaria Data Acquisition

Malaria is a life-threatening, mosquito-borne infectious disease caused by single-celled protozoan parasites. We scrape the variables of interest by locating the required API keys, using our function to obtain the clean data, and joining the variables together to create the final dataset.

Download Malaria Indicators

First, we find relevant malaria API indicators using the GHO API index (usinghttps://ghoapi.azureedge.net/api/Indicator) by searching within the document for “malaria”. We then use our function to obtain the variables of interest.

# Estimated malaria cases
malaria_cases <- get_who_data(
  "MALARIA_EST_CASES", "cases"
)

# Estimated malaria deaths
malaria_deaths <- get_who_data(
  "MALARIA_EST_DEATHS", "deaths"
)

# Estimated malaria incidence
malaria_incidence <- get_who_data(
  "MALARIA_EST_INCIDENCE", "incidence_rate"
)

# Estimated malaria mortality
malaria_mortality <- get_who_data(
  "MALARIA_EST_MORTALITY", "mortality_rate"
)

Data Cleaning and Tidying

We combine the four datasets using country codes and years. A full_join() preserves observations even when some indicators are unavailable.

malaria_final <- malaria_cases |>
  full_join(
    malaria_deaths,
    by = c("country_code", "year")
  ) |>
  full_join(
    malaria_incidence,
    by = c("country_code", "year")
  ) |>
  full_join(
    malaria_mortality,
    by = c("country_code", "year")
  ) |>
  mutate(
    disease = "Malaria",
    category = "Mosquito & Vector-Borne"
  ) |>
  relocate(disease, category, country_code, year)

HIV Data Acquisition

Human Immunodeficiency Virus (HIV) is a retrovirus transmitted through bodily fluid that attacks and destroys the body’s infection-fighting CD4 white blood cells, weakening the immune system.

Download HIV/AIDS Indicators

# Number of new HIV infections
HIV_cases <- get_who_data(
  "HIV_0000000001", "cases"
)

# Number of HIV-related deaths
HIV_deaths <- get_who_data(
  "HIV_0000000006", "deaths"
)

# HIV incidence per 1,000 uninfected population
HIV_incidence <- get_who_data(
  "SDGHIV", "incidence_rate"
)

# HIV/AIDS mortality per 100,000 population
HIV_mortality <- get_who_data(
  "WHS2_138", "mortality_rate"
)
# Combine all four HIV indicators
HIV_final <- HIV_cases |>
  full_join(
    HIV_deaths,
    by = c("country_code", "year")
  ) |>
  full_join(
    HIV_incidence,
    by = c("country_code", "year")
  ) |>
  full_join(
    HIV_mortality,
    by = c("country_code", "year")
  ) |>
  mutate(
    disease = "HIV/AIDS",
    category = "Other Major Pathogens"
  ) |>
  relocate(disease, category, country_code, year)

Ethical Data Acquisition Reflection

Our data is retrieved from WHO’s publicly accessible Global Health Observatory API. As we obtained our data, We use documented API endpoints instead of directly scraping website content. We also preserve missing values and uncertainty bounds to avoid misrepresenting the statistics. Although we don’t plan to use the high and low uncertainty bounds in our plotting, they are a strong representation of the variability in global estimates, which we will address in our final project. Lastly, our API requests were limited to only the indicators needed for our project.

Reflection of collaboration techniques

As we worked on data scraping, it worked best for us to work side by side and talk through what we were doing. We toyed around with creating separate branches for different edits but found that it worked best to discuss edits and go one at a time. After one of us had made a change, we ensured to pull the changes before editing again. Clearly communicating these steps made collaboration easy. Going forward, relying on discussing changes in person may not be sustainable so we will look into utilizing more github collaboration skills. Using branches, issues, and pull requests will make editing remotely smooth and organized.

Future Application

The datasets we created are a great start as we plan our interactive global disease dashboard. Moving forward, we suspect that combining the three datasets could make comparison between the statistics easier to visualize. Doing so will require merging and filtering to include countries with statistics for all three diseases. Additionally, as we think about creating choropleth maps, finding ways to join polygon data for each country is a next step that could require some renaming (country code to full name) and joining. Lastly, scraping some basic data on the quality of life and economy of each country over time could be an additional layer of complexity to help make our dashboard more engaging. For now, we have the data to see how three of the most widespread global diseases have spread over time.
